# 小猿家评测助手

把 `小猿家` 文件夹作为 Chrome 扩展加载即可使用。

## 功能

- 在 `https://eval.yuanfudao.com/#/task/question-eval/` 页面自动显示“评测”悬浮按钮。
- 一键设置：
  - 参考答案：默认“原题”
  - 漏空数：默认“0”
  - 各小空：默认“正确”，可切换为“不可批改”等小空选项
  - 漏题数：默认“0”
- 不提供“多余框/重复框”“全部正确”“不是题单”的批量一键入口。

## 使用

1. 打开 Chrome 扩展管理页。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择 `小猿家` 文件夹。
4. 打开小猿家 Eval 评测页面，点击右侧“评测”按钮后运行。
