# agents.md

## 目标
- 在 `mapi.yuanfudao.com` 和 `online-venv.yuanfudao.com` 的整页批改评测页面中，提供一个悬浮窗式自动评测插件。
- 支持评测 6 个 Tab：`作答结果`、`手写识别`、`分数识别`、`固定批改`、`答案框`、`题目框`。

## 范围与约束
- 插件名称：`评测助手（AI&答题卡）`。
- 采用 Content Script 注入方式，在页面右侧 1/4 处显示“评测”悬浮按钮。
- 评测项支持独立勾选与独立一键评测：
  - 作答结果：一致 / 不一致 / 半对 / 忽略 / 未作答 (含算法可解)
  - 手写识别：一致 / 不一致 / 忽略
  - 分数识别：一致 / 不一致 / 忽略 (含分数框识别、算法可解)
  - 固定批改：对 / 错 / 半对 / 忽略 / 未批改 (含算法可解)
  - 答案框：对 / 错 / 忽略
  - 题目框：对 / 错 / 忽略
- “算法可解”、“分数框识别”采用次级标题样式（字体较小、右移、加“-”前缀）。
- 完成提示文案：`评测完成：更改 ${totalChanged} 项`。
- 配置记忆：勾选状态与下拉选项需持久化。

## 关键行为规则
- 只在对应 Tab 内应用对应规则。
- `答案框` Tab 里，遇到自由批改类（如含 `无留痕` 选项）必须跳过，避免误改。
- 运行后自动隐藏配置面板。
- URL 过滤：自动识别 `holepage` 和 `cardPage` 路径。对于非匹配页面，支持通过点击扩展图标手动呼出按钮。
