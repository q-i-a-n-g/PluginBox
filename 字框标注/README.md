# 字框标注助手

一个仅作用于算法评测系统作文正文单字框 OCR 样本页的 Chrome Manifest V3 扩展。

它只操作页面当前的未保存 React 草稿，不直接请求或修改服务器接口。永久写回仍由你点击页面原有的“保存标注”。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`/Users/neirong/Desktop/20/ocr-box-helper/`。
5. 打开或刷新以下类型的样本页：
   `https://metis-aione-test.zhenguanyu.com/metis-aione-eval/samples/<样本 ID>`

页面右上角会出现“字框标注助手”工具栏。

如果工具栏遮住页面右侧内容，可点击标题栏中的“收起”；再次点击“展开”即可恢复。

点击 Chrome 工具栏中的扩展图标，可以随时显示或隐藏助手界面。如果当前样本页在扩展加载前就已打开，首次点击图标会主动加载并显示助手，不必刷新页面。扩展图标需要先从 Chrome 的“扩展程序”菜单固定到工具栏，或直接在该菜单中点击。

## 使用

### 单击画框

点击字的中心，插件会以该点为中心生成固定尺寸的字框，并自动限制在图片范围内。

- 默认尺寸固定为 `50 × 60` 原图像素，不受页面缩放影响。
- 点击“缩小”或“放大”会按 10% 等比例调整宽高，范围为 40%–300%。
- 缩放比例会由 Chrome 本地存储记住；旧版本保存的自定义宽高设置不再使用。
- 成框后自动选择下一字；如果中间是常见中英文标点，会连续跳过标点。
- “反向标注”默认关闭；勾选后，成框会改为自动选择上一字，从后往前连续标注，途中同样跳过标点。
- 进入“单击画框”后，如果连续 5 秒没有单击图片画框，会自动切换到“暂停助手”。此功能只使用一个一次性定时器，不进行持续轮询。

### 暂停助手

默认模式。处于“暂停助手”时，插件不拦截图片指针事件，页面原有的拖拽画框、选择和移动已有框功能保持可用。原有键盘左右键始终保留。从“暂停助手”切回“单击画框”时，会按照当前正向或反向设置自动选择相邻的非标点字符，然后恢复助手绘框。

### 清空全部字框

点击“清空全部字框”后会立即开始，无需二次确认。插件会逐个调用页面原有的“删除字框”，清空进度和结果显示在页面右下角，完成后自动消失；清空完成后会选择第一个字符。

重要边界：

- 清空只改变当前页面的未保存草稿，不会自动点击“保存标注”。
- 如果误清空，在点击保存前刷新页面即可从服务器重新加载原数据。
- 一旦点击页面原有“保存标注”，当前草稿就会按网站原流程永久写回。
- 清空过程中如果切换样本、组件重建或某一步没有成功，插件会中止并显示已完成进度，不会无限重试。

### 连续删除 5 个

点击“连续删除 5 个”，会从当前字符开始（当前字符有框时包含当前字符），向后删除 5 个实际存在的字框；原本无框的字符会跳过。完成后自动选择最后删除位置的下一个字符，再次点击即可继续删除下一批 5 个。该按钮在暂停助手和单击画框模式下均可使用，也不会自动保存。

### 清空标点字框

点击“清空标点字框”，会删除所有已有字框的中英文标点符号，普通文字和数字字框不受影响。按钮位于“连续删除 5 个”和“清空全部字框”之间；完成后恢复原来选中的字符，也不会自动保存。

## 权限与实现边界

- 仅匹配 `metis-aione-test.zhenguanyu.com` 的样本详情路径。
- 申请 `storage` 权限记忆模式、自动跳字方向和固定框缩放比例。
- 申请 `activeTab` 和 `scripting`，仅在用户点击扩展图标时向当前受支持的样本页加载或切换助手界面。
- 没有后台服务、远程代码、额外网络请求或直接 GT API 写入。
- 插件依赖页面现有的可访问性标签。如果网站重命名绘图区域、“删除字框”或前后字符控件，工具栏会禁用并显示兼容性提示。

## 排障

- 工具栏显示“等待页面加载”：确认当前是作文正文单字框 OCR 样本页，并尝试刷新。
- 工具栏显示“只读”：确认数据集处于允许修改 GT 的状态，且页面当前没有正在保存。
- 清空后想恢复：不要点击保存，直接刷新页面。
